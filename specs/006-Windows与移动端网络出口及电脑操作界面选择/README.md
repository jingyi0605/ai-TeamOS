# Spec 006：Windows 与移动端网络出口及电脑操作界面选择

状态：IN_PROGRESS

本 Spec 处理三件相互关联的事情：

1. 让 Windows Desktop 成为与 macOS/Linux Desktop 相同的浏览器网络出口提供者。
2. 评估 Android 与 iOS 作为网络出口提供者的技术可行性，并记录下一阶段边界。
3. 在电脑操作界面中提供当前网络出口查看与手动切换入口，复用服务端已有的 ranked sourceOrder、revision、lease 和 route epoch 机制。
